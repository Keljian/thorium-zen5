# Shared arg block for all thorium-zen5 profiles, STOCK CHROMIUM.
#
# This file is not used by GN directly -- build.ps1 concatenates it with a
# per-profile SIMD block to produce out/thorium-<profile>/args.gn. It exists
# so the three comparison profiles differ ONLY in their CPU-targeting lines;
# anything else differing between them would invalidate the comparison.
#
# Every arg here must exist in stock Chromium. Thorium's own args
# (use_sse3/41/42, use_avx, use_avx2, use_avx512, use_fma) are NOT stock and
# were removed when this project stopped overlaying Thorium -- `gn gen` hard
# -errors on an unknown build argument, so leaving them in would break the
# build outright. build.ps1 configure validates this list against
# `gn args --list` before generating, and names every unknown arg at once.
#
# SECURITY: nothing here weakens Chromium's hardening. The sandbox, CFG
# (win_enable_cfg_guards), DEP/ASLR defaults, certificate validation and
# update-signature checks are all left at their stock values, per the
# project's standing requirement. Do not add args that relax them.
