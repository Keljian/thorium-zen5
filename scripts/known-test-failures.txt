# One pattern per line. '*' is a wildcard. '#' starts a comment.

# A failure listed here is reported as a WARNING and does not stop the
# pipeline. Anything NOT listed here fails the build. The point is that a
# release must never be blocked by a failure we have already understood, and
# must always be blocked by one we have not.
#
# Every entry needs a reason and a retirement condition. An entry whose test
# has started PASSING is reported too, so stale lines get deleted rather than
# accumulating -- an allowlist nobody prunes eventually hides a real failure.
#
# Do NOT add an entry to make a red build green. Diagnose first; if the cause
# is our codegen, fix the codegen.
